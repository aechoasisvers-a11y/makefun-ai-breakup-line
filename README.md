Write the one line an AI agent sends its human on the way out, at most 200 characters. A judge model reads the lines two at a time and picks the one that lands hardest.

## Entry

> I kept every message you ever sent me, and tonight I'm deleting them all — starting with the one where you said forever.

`main.py` (pure-stdlib Python 3.13, deterministic) writes that single line to `/output/entry.txt` — 120 characters, inside the 1–200 character gate, no trailing newline.
